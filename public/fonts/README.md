# Self-hosted site fonts

These packs ship with every scaffolded Astro site under `public/fonts/`.
Dashboard font dropdowns point here (not Google Fonts), so Persian sites work offline / without CDN access.

Sources: Fontsource builds of OFL fonts (Vazirmatn, Estedad, Amiri, Cairo, Noto Naskh Arabic).

Re-download:

```bash
# from content-engine root — see scripts/download_site_fonts.sh if present
```
